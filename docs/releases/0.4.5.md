# Geophysics Workbench 0.4.5: misfit and measured data on the section

You can now load what your inversion was fitted to, next to the model and the context:

- **measured data** as an apparent-resistivity pseudosection;
- **the misfit of an inversion**: how far the model's calculated data are from the
  measured data, reading by reading.

## What's new

- **Measured data and misfit as section layers.** Add them with **Add ERT model…**, like a
  model.
  - **pyGIMLi / BERT data files** (`.data`, `.ohm`) are read directly.
    - Add the model response (BERT's `response.vector`, or a response saved from pyGIMLi)
      and the layer shows the misfit.
    - The dialog finds `response.vector`, `<name>_response.vector`, `<name>.response` or
      `dcinv.response` next to the data file by itself.
    - Without a response, you get the measured pseudosection.
  - **R2 / ResIPy** `f001_err.dat`: observed vs. calculated apparent resistivity. The
    electrode positions come from ResIPy's `electrodes.dat` in the same folder.
    - Checked on a real R2 run: the first 80 electrodes of Gülpe transect 3, through
      ResIPy. The χ² computed from R2's normalised misfit matches R2's own final RMS of
      1.00.
- **One dot per reading.**
  - Each reading sits at its midpoint, at the median depth of investigation (Edwards 1977)
    of its actual A B M N, hung below the ground line. That works for any array: Wenner,
    Schlumberger, dipole-dipole, pole-dipole, gradient.
  - **Misfit** is (calculated − measured) / measured in %, on a red–yellow–blue scale
    centred on 0.
- **Display…** for these layers:
  - **Show:** misfit, measured or calculated apparent resistivity.
  - **Draw as:** Points (the default), or the smooth field, contours, or both, as for models.
- **Readout.** Hover a dot to see its electrodes, measured and calculated value, and misfit,
  e.g. `T3 misfit: 4.2 % (A 12.0 B 15.0 M 13.0 N 14.0 · meas 96.3 · calc 100 Ω·m)`.
- **Misfit summary…** in the layer's right-click menu. It shows a histogram of the misfit
  per reading, the RMS misfit, χ², the number of readings, and the source and response
  files.
- **Safety checks.** Each of these gives a clear error instead of a wrong picture:
  - a data file and a response that don't belong together (different counts);
  - electrode numbers outside the electrode list;
  - calculated values that are all zero;
  - unknown column units;
  - a 3D electrode layout;
  - an R2 file whose columns aren't R2's, or whose misfit disagrees with the final RMS in
    `R2.out` next to it.

  Column units such as `err/%`, `u/mV` and `i/mA` are applied. Remote electrodes far off
  the line count as poles.
- **Misfit layers are not used in the tie strips** at profile crossings. Only models are.

## Demo (Gülpe, transect 3)

- I re-inverted the authors' measured data of transect 3 once with pyGIMLi 1.5.5, following
  their BERT settings: λ = 100, robust data, paraDX 0.25, quality 34. The run gives an RMS
  misfit of 8.0 % and χ² of 3.96. The script is `scripts/invert_guelpe.py`.
- The demo build (`scripts/build_demo_guelpe.py`) adds the layer **"Transect 3 misfit
  (pyGIMLi re-inversion)"**.
- **Your local demo GeoPackage holds your own test drawings**, so I didn't rebuild it.
  Either run the build after deciding about your drawings, or add
  `demo_guelpe/data/ert/T3/T3_measured.data` with **Add ERT model…**. Its response file is
  found automatically.

## What to try

1. Gülpe, Transect 3: **Add ERT model…** → `data/ert/T3/T3_measured.data`. The response is
   filled in, and the preview shows 4524 readings and a misfit RMS of 8.0 %.
2. Hide the model layer and look at the misfit dots: where does the model fit badly?
3. Right-click the layer → **Misfit summary…**.
4. **Display…** → Show: Measured, Draw as: Smooth field + contours. This gives the
   apparent-resistivity pseudosection.
5. Hover a dot to read its electrodes and values.

## Known limits

- **ZondRes2D and Res2DInv misfit are not supported yet.**
  - Neither format is publicly documented.
  - Res2DInv's `.inv` file is only parsed by other tools at fixed row positions that
    depend on the instrument.
  - Following the design, nothing is guessed from documentation: send one export from each
    program and the readers come next.
- χ² is computed from the file's data errors, by plain least squares. The inversion's own
  χ² can differ when it weighted data robustly: pyGIMLi reports 3.96 for transect 3, the
  plain value is 4.11.
- The "n-level" pseudo-depth alternative is not built. The median depth of investigation
  works for every array.
- The misfit summary is a separate small window, not a docked panel.
