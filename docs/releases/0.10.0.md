# Groundwork 0.10.0: the plugin is called Groundwork

The plugin is now called **Groundwork**, with the subtitle "geophysical profiles in QGIS". It was
called Geophysics Workbench. That name was too close to AGS Workbench (formerly Aarhus
Workbench), an established commercial ERT package, and the plugin is about to be public.
Nothing else changes in how it works.

## One-time step

1. In **Plugins → Manage and Install Plugins**, uninstall **Geophysics Workbench**.
2. Restart QGIS. Otherwise plates made in the same session can lose their colour bars and
   legends.
3. Install `groundwork_geophysics-0.10.0.zip` with **Install from ZIP**.

Groundwork warns while the old plugin is still installed, so you will not run both by mistake.

## What stays

- Your projects and their workbench files keep working. Nothing needs renaming.
- In an old project the layer group keeps its name; Groundwork finds it and uses it.
- QGIS remembers the sizes of the panel and the dialogs.

## What is new, by name

- The menu is **Groundwork**. **New Groundwork Project…** suggests `<project>_groundwork.gpkg`
  next to the QGIS project.
- The demos ship as `demo_groundwork.gpkg`, `guelpe_groundwork.gpkg` and
  `erfurt_groundwork.gpkg`, in a layer group "Groundwork". The demo zips are called
  `groundwork_geophysics-demo[-guelpe|-erfurt]-0.10.0.zip`.
