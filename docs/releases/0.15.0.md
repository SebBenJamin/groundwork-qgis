# Groundwork 0.15.0: big models, interpolation and one style for all lines

Large model exports open fast, the smooth display can be gridded by other methods, and a
whole survey can be added and styled in a few clicks.

## Big models, fast

- Sections, contours and 3D of models with hundreds of thousands to millions of cells draw
  much faster. **Show in 3D…** opens in about a second (it took a minute on an 11-line
  project), and a 2-million-row file loads without running out of memory.
- **Coarser cells:** some programs export their models interpolated to a very fine grid
  (0.25 × 0.1 m, over a million points). For such a text table (more than 100 000 points on a
  regular grid) **Add Data** offers *Read as cells of [dx] × [dz] m*: blocks of points are
  averaged into larger cells (resistivity on a log scale). **Dataset info** and plates say the
  model was averaged, and from how fine a grid.
- A model whose export fills its rectangle with -9999 no longer gets a flat ground: its ground
  is the top of the cells that have a value.

## How the smooth field is drawn: Interpolation

**Display…** has a new **Interpolation** group for the smooth field and the contours:
**Linear** (as before), **Nearest**, **Inverse distance**, **Spline** and **Kriging**, with
the variogram fitted to the data or typed in, and the horizontal-to-vertical anisotropy found
automatically or typed. The method is part of the model's look, so 3D and plates use it too.
When a method cannot be used for a model (for example, not enough memory), the field is drawn
linearly and the reason is written to **Log Messages** (Groundwork tab). See
[The section panel](../user/howto/section-panel.md#interpolation).

## A whole survey at once

- **Add Data** takes several files. A table lists each file with the profile guessed from its
  name (`L5`, `Line_05` → *Line 5*), which you can change. Files in map coordinates without a
  matching profile get a new one. Columns and settings are taken from the first file.
- A model's section style (colours and their range, display, contours, interpolation,
  coverage fade, opacity, shown or hidden) is **saved with the QGIS project**. Before, every
  model started again from the automatic colours when the project was opened.
- **Apply Style to All Sections** (right-click a model in the layer list) gives every other
  model of the same method, on every profile, this model's look: ERT to ERT only, never to
  refraction, and only to models in the same unit. **Ctrl+Z** takes it back in one step.

## Section panel

- **Zoom Map to Profile** (the magnifier next to the profile list).
- Arrows next to the profile list, and **Page Up** / **Page Down**, step through the profiles.
- **Copy Section Image** and **Save Section Image…** (the picture button).
- The vertical exaggeration box shows its whole "Auto (x)" text; long layer names are shortened
  in the middle, so the end of the name stays readable.

## Plates

- Choosing another template for an existing plate makes its layout again (after asking).
- Legend blocks with nothing in them (no field notes, no interpretation) are left out.
- A plate reserves its space above the sections in millimetres, so the layout is the same on
  every screen.

## Fixes

- A project saved without the interpretation layers gets them back when it is opened; before,
  they came only with the next edit.
- 3D point clouds are drawn at full detail (maximum screen space error 0.1 px), so many
  curtains seen from a distance stay in colour instead of turning black. Clouds made with 0.14
  get it once; a value you set stays.
- Counts of cells and points are grouped in threes ("623 241 cells").

## Updating

Install `groundwork_geophysics-0.15.0.zip` (Plugins → Manage and Install Plugins… → Install
from ZIP). A project saved with 0.15 opens in 0.14, but a model read as coarser cells shows an
error there, and 0.14 ignores the saved section styles and interpolation. The demos are
unchanged.
