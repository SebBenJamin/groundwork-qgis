# Geophysics Workbench 0.9.1: several surface strips

The surface geology band is now a list of strips. Several polygon layers (for example a
detailed and a regional geology map) are drawn one above the other over the ground of the
section, each with its own title.

## What's new

**Surface strips**
- **Context Layers… › Band and DEM** lists the strips. Add a polygon layer, choose the field
  that names its units, type a title (the layer's name is used when you leave it empty) and
  switch it on or off with **Shown**. The first row is the top strip.
- The colours come from each layer's QGIS style, as before.
- Along a profile only the strips that have polygons there are drawn, in the order of the
  list, without gaps. A layer that cannot be loaded drops only its own strip.

## Existing projects

A project with one band keeps it: it loads as a list with one strip and looks as before.
Saving writes the first shown strip also in the old form, so an older plugin still shows one
strip.

## Demo

The Gülpe demo shows two strips, **GÜK 300** above **GK 25**. The GÜK 300 map layer itself
stays switched off on the map (at 1 : 300 000 the whole demo area is one polygon). The
project and the workbench store of `demo_guelpe/` were rebuilt for this release.
