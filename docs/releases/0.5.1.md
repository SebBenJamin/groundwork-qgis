# Geophysics Workbench 0.5.1: fixes after the 0.5.0 review

Small fixes; nothing changes in how you work.

- **Viewer options** (spacing, axis, display switches, label font) are saved in the project when you change them, not when the window closes. Closing QGIS or opening another project no longer writes the viewer's options into the wrong project.
- **Curve styles saved in the project are checked value by value.** A hand-edited or damaged value falls back to its default instead of stopping the section from drawing its context. Curve style… no longer accepts "nan" or "inf" as min or max.
- **Log scales:** a minimum of 0 or below (impossible on a log scale) now uses the smallest positive value, so the curve still shows. A track with nothing to draw still shows the curve's name.
- **Readout:**
  - on a log scale, it no longer interpolates across samples ≤ 0 that the line leaves out;
  - small values are shown with their digits (0.004 S/m, not 0.0).
- **Classes you untick** in Borehole style are drawn as an empty, outlined interval. Before, they got a neutral colour. Values without any class still get their neutral colour.
- **Swapped top and bottom:** intervals whose top lies below their bottom are still used swapped, and now the QGIS log says so (once per borehole).
- **Hover and click on the section** also work over a borehole's curve tracks and layer text, not only its column. Tie strips keep clear of them.
- **"On the section"** in the viewer applies to every borehole entry. A tooltip and the user guide now say so.
- **Unloading the plugin** removes only its own pattern folder from QGIS's SVG paths, keeping paths that other plugins added.
- **Decimal commas:** numbers written with a decimal comma ("0,4", "31,2") in text columns, e.g. from a German CSV, are read. Before, those rows were skipped without a message.
- Code tidy-up: long lines re-wrapped.
