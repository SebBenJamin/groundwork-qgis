# Geophysics Workbench 0.3.5: interpretation across profiles

One anomaly often shows on several parallel profiles. In 0.3.5 one feature, for example
"A · conductive body", can have pieces on as many profiles as you like. You can also regroup and
retype what you drew at any time, without redrawing.

## What's new

- **Features span profiles.** When you finish a piece, the form's first row is
  **Feature**. Choose **New feature**, or pick an existing one such as "A · conductive body".
  Each entry says which profiles the feature is on and how many pieces it has, for example
  "sand — Transect 3 (here), Transect 2 · 2 pieces". A line below the entry says what
  joining it does. The piece then joins that feature. Its type, letter, confidence and note are shared, so you
  edit them once.
- **Regroup without redrawing.** Right-click a piece in **Edit** mode for these options:
  - **Attributes…**
  - **Move piece to**: another feature, or **New feature**, which splits the piece off with
    the same attributes and no letter.
  - **Merge this feature into**: all of its pieces join the other feature.
  - **Delete piece**

  Every one of these is a single Undo step.
- **Types…** lists the types in use with their feature counts. **Rename…** changes a type
  in every feature of the current version. A name already in use (in any case) merges the two
  types.
- **Snap** (on by default). While you draw or drag a vertex, points snap to the first of
  these in reach:
  1. vertices of anything already drawn on the profile;
  2. borehole layer boundaries;
  3. the ground line.
- **Crossing markers.** Where another profile crosses, its interpretation shows at the tie
  strip with its letter:
  - polygons as translucent bars;
  - lines as ticks;
  - points as diamonds.
- **Compare.** On the version bar, **Compare** draws a frozen version faintly behind the
  one you are working on.
- **Export…** writes 3D pieces to **GeoPackage** or **DXF**:
  - In **Edit** with a piece selected, it writes that piece's feature.
  - Otherwise, it writes every feature of the shown version.
  - GeoPackage gets one layer each for lines, polygons and points, with the attributes.
  - DXF puts every piece on a layer named after its feature, for example "A - conductive
    body".
- **Fixes:**
  - Profiles without station heights now use the DEM line as their surface, so boreholes
    and labels show.
  - Changing a layer's style or drawing no longer re-reads every context layer and the
    DEM.

## What to try

1. Open Transect 3 and draw a polygon, A · "conductive body".
2. Open another transect and draw a polygon. In the form, choose **Feature: A ·
   conductive body**. On the map, both footprints are labelled A.
3. Right-click the second piece, then choose **Move piece to → New feature**. Then press
   Undo.
4. Open **Types…** and rename "conductive body" to "conductive anomaly".
5. Draw a line close to a vertex of the polygon. It snaps onto the vertex. Switch **Snap**
   off and try again.
6. **Freeze…** the version as "R1", move a vertex, then set **Compare** to R1.
7. Choose **Export…** and save to a .dxf file. Open it in a CAD viewer or drag it into QGIS.

## Known limits

- The Gülpe demo transects don't cross, so crossing markers need profiles that do, for
  example the synthetic demo or your own data.
- DXF layer names are plain ASCII: ä/ö/ü/ß become ae/oe/ue/ss, and other special characters
  become "_".
- Exported polygons that are folded at profile bends are written as they are. There is no
  splitting into flat pieces.
- Undo covers the current profile session, as before.
