# Geophysics Workbench 0.3.0: interpretation on the section

You can now interpret directly on the section. Draw lines for layer boundaries, polygons for
anomalies, bodies or unreliable zones, and points for picks. Everything you draw is real GIS
data from the first click:
- **Geolocated in 3D.** Every vertex gets its true x, y and elevation, exactly along bent
  profiles.
- **Stored in the project's GeoPackage.**
- **Shown on the map,** as 3D layers and as footprints labelled with the reference letter.

## What's new

- **An interpretation row on the section panel:** **Pan · Line · Polygon · Point · Edit ·
  Undo · Redo**, and on the right the **Version** bar.
- **Drawing:**
  - Click to add vertices, double-click or Enter to finish.
  - Backspace removes the last vertex.
  - Esc clears the sketch; a second Esc returns to Pan.
- **Your own words.** After drawing, a small form asks for:
  - **Type**: free text. The list only suggests types you have already used, plus a few
    starters.
  - **Letter**, for example A or B2. You get a warning if the letter is already used, but
    it's still allowed.
  - **Confidence**: certain, probable or uncertain.
  - **Note**.

  Everything can stay empty: draw first, decide later.
- **Editing (Edit tool):**
  - Click a piece to select it.
  - Drag a vertex to move it.
  - Click an edge to insert a vertex.
  - Drag inside a polygon, or Shift-drag a line, to move the whole piece.
  - **Delete** removes the selected vertex, or the whole piece after asking.
  - Double-click edits the attributes.
  - Undo and Redo cover all of these.
- **Confidence as line style:** solid for certain, dashed for probable, dotted for
  uncertain, grey for not set. The section and the map use the same QGIS layer style, so
  restyle the layers in QGIS and the section follows.
- **Your own fields.** Open **Interpretation features (attributes)** in the layer panel,
  add any field (for example *drill target*) and fill it in the attribute table or with the
  field calculator. The 3D layers pick it up.
- **Versions:**
  - **Freeze…** keeps the current interpretation as a named, read-only version, for example
    "Report 1", and you carry on working.
  - Pick a frozen version in the **Version** list to view it. The tools are disabled while
    you do.
  - **Start from this version** makes it the current one again. It offers to freeze your
    present work first.

## How to update

1. Install `geophysics_workbench-0.3.0.zip`: **Plugins → Manage and Install Plugins…
   → Install from ZIP** (German QGIS: **Erweiterungen → … → Aus ZIP installieren**). Then
   restart QGIS.
2. Existing projects keep working. The interpretation tables are created the first time
   you draw.

## What to try (Gülpe demo, Transect 3)

1. Open `guelpe_project.qgz` and pick **Transect 3**.
2. Click **Polygon** and draw around the low-resistivity body near 115–140 m. Give it any
   type you like, the letter **A**, and leave probable.
3. Click **Edit**, select the polygon, drag one corner, then click **Undo**.
4. Click **Freeze…** and name the version "Test".
5. Select the polygon, press **Delete**, and confirm.
6. Choose "Test" in the **Version** list. The polygon is back, read-only. Click **Start from
   this version** and choose **Replace**.
7. Look at the map. The group **Geophysics Workbench → Interpretation** holds the polygon in
   3D, and its footprint along the transect is labelled **A**. In QGIS's 3D view the polygon
   stands upright under the transect.

## Known limits (coming in 0.3.5)

- One piece per feature. Linking the same anomaly across several profiles comes next.
- No snapping yet, to the ground line, borehole layers or other vertices.
- Renaming or merging a type everywhere at once, comparing a frozen version faintly behind
  the current one, and regrouping pieces all come next.
- Interpretation of other profiles is not shown at crossings yet.
