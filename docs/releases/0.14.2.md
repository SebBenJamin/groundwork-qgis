# Groundwork 0.14.2: -9999 map coordinates left out

A fix for text tables with map coordinates (easting, northing, depth, value).

## Rows without a map position are left out

Some programs export cells past the surveyed line with **-9999** as easting and northing.
Groundwork placed those rows on the map like real points, so the profile line built from
the file ran off to (-9999, -9999): a 642 m line became 3480 km long.

A row whose easting or northing is -9999 now counts as having no map position. It is left
out of the profile line and is not placed on the section. **Add Data** says so: the preview
warns "N rows have no map position (-9999) and will be left out", and after adding it says
how many rows of the whole file were left out. They are no longer counted as blank cells.
A file in which no row has a map position is refused with a message.

## Updating

Install `groundwork_geophysics-0.14.2.zip` (Plugins → Manage and Install Plugins… →
Install from ZIP). If a profile was made from such a file with 0.14.1 or older, delete
that profile and add the file again. The demos are unchanged.
