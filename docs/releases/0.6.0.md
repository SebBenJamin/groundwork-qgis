# Geophysics Workbench 0.6.0: field notes, Dataset info and report plates

## What's new

- **Field notes** record what the field crew saw along a profile: "electrodes 23–28 disabled (farmer)", "fence at 140 m". A note is set at one place or along a stretch.
  - On the section, the **Note** tool adds one with a click or a drag. **Field notes…** in the Interpretation menu lists, edits and hides notes; you can also add a note by electrode numbers.
  - On the map, the layers "Field notes" and "Field notes (stretches)" show the notes.
  - Hidden notes are kept, but appear neither on the section nor on plates.
- **Dataset info…** (right-click a layer in the section's layer list) records method, array, spacing, date, software, reference and a note. Plates show this as each section's provenance line. Fields left empty are left out; nothing is invented.
- **Plates…** makes report plates as ordinary QGIS print layouts:
  - four templates, A4 and A3, each portrait and landscape, or your own `.qpt`;
  - several section frames per plate, each with its own look ("Take from section panel");
  - fit to page at a standard scale and VE, shared by frames of the same profile;
  - tunable colour bars;
  - an interpretation legend and a borehole legend (classes and curves);
  - the field-notes list;
  - a mini-map with the profile highlighted, a north arrow, a bar scale and the coordinate system;
  - a title block with project, client, job, date, author and revision (**Plate details…**).
- **Export plates…** updates every plate and writes vector PDFs: one per plate, or one combined file.
- **Updating a plate** refreshes only the plugin's own content. What you moved, restyled or added in the layout designer stays.
- **The Gülpe demo** has one plate: A3 landscape, Transect 3.

User guides: [Report plates](../user/howto/plates.md), [Field notes](../user/howto/field-notes.md), [Dataset info](../user/howto/dataset-info.md).

## What to try

1. Open the Gülpe demo and open Transect 3 in the section panel.
2. Choose the **Note** tool and drag along a stretch of the profile. Write a note, for example "test: electrodes 10–14 skipped". (The demo has no field notes: the published data has none, and invented observations do not belong in a real-data demo.)
3. Right-click the model in the layer list → **Dataset info…**. Enter, for example, the array and spacing.
4. **Geophysics Workbench → Plates…**. Plate 1 – Transect 3 is listed.
   - **Plate details…**: enter your own project and client.
   - **Create / update plates**, then open the plate from the Layout Manager. The note, the provenance line and the title block are on it.
5. In the layout designer:
   - move the legend;
   - add a text box;
   - select the colour bar and change its ticks to `list:10,30,100,300`.

   Then run **Create / update plates** again. Your changes stay.

6. Add a second frame with the misfit layer of the same profile. Both frames get the same scale and VE.
7. **Export plates…** into a folder, once per plate and once with **One combined PDF**.

## Known limits

- The section frames show the scale as a ratio and on the distance axis. There is no separate bar scale for sections, because QGIS's scale bar only links to maps.
- A plate's frames are laid out again when you change the number of frames. Moves you made to the plugin's own frames and colour bars are then lost; everything else stays.
- Borehole context is gathered while the plate is drawn. Live (WFS) layers need a connection, as in the section panel.
- At plate scale, dense context can look crowded: many stations, points or the geology band. Switch context off for that frame in the panel, then use **Take from section panel**.
- In QGIS 4.2, the frame's own outline is drawn at the wrong size in exports. The plugin therefore leaves it off; the plot's border frames the section instead.
